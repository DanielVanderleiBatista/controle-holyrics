Configuração de conexão

Preencha os campos abaixo depois de seguir os passos no computador que roda a Holyrics:

  1. 1 Menu Arquivo → Configurações → API Server
  2. 2 Em "API Server – Local", ative e anote a Porta (padrão 8091)
  3. 3 Clique em "Gerenciar permissões" e crie um token novo
  4. 4 Copie o token gerado e cole no campo abaixo
⚠️

Importante: depois de criar o token, marque todas as permissões disponíveis na coluna "Local" — não só algumas. Esse app usa apresentação, tela, player de mídia, playlist de músicas, biblioteca de mídia e Bíblia; se faltar liberar alguma, aquele botão específico vai dar erro de "unauthorized action" sem aviso claro.

Celular e computador precisam estar na mesma rede wifi. O IP é o da rede local (ex: 192.168.x.x) — não use o IP de VPNs como Radmin.
